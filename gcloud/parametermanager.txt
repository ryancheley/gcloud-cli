NAME
    gcloud parametermanager - parameter Manager is a single source of truth for
        your parameters

SYNOPSIS
    gcloud parametermanager GROUP [GCLOUD_WIDE_FLAG ...]

DESCRIPTION
    Parameter Manager stores, accesses, and manages the lifecycle of your
    application parameters. It aims to make management of sensitive application
    parameters effortless for customers without diminishing focus on security.

GCLOUD WIDE FLAGS
    These flags are available to all commands: --help.

    Run $ gcloud help for details.

GROUPS
    GROUP is one of the following:

     parameters
        Manage Parameter Manager parameter resources.

     templates
        Manage Parameter Manager template resources.

NOTES
    This variant is also available:

        $ gcloud beta parametermanager
