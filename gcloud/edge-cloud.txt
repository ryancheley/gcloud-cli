NAME
    gcloud edge-cloud - manage edge-cloud resources

SYNOPSIS
    gcloud edge-cloud GROUP [GCLOUD_WIDE_FLAG ...]

DESCRIPTION
    Manage edge-cloud resources.

GCLOUD WIDE FLAGS
    These flags are available to all commands: --help.

    Run $ gcloud help for details.

GROUPS
    GROUP is one of the following:

     api-keys
        Read and manipulate API keys for Google Distributed Cloud.

     container
        Manage Edge Container resources.

     networking
        Manage Distributed Cloud Edge Network resources.

     projects
        Google Distributed Cloud Connected Project gcloud commands.

     service-accounts
        Google Distributed Cloud Service Account gcloud commands.

     services
        GDC Connected Service gcloud commands.

     zones
        Manage zone operations for Google Distributed Cloud.

NOTES
    This variant is also available:

        $ gcloud alpha edge-cloud
